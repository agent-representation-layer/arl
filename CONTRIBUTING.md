## Contributing to Agent Representation Layer (ARL)

Thank you for your interest in contributing to ARL.

ARL is an open architectural proposal exploring how autonomous agents can represent people through contextual identities while remaining interoperable with emerging standards such as A2A and MCP.

At this stage, the project is intentionally focused on discussion rather than implementation.

### Current Stage

The project is currently validating:

whether the problem is real;
whether similar work already exists;
the architectural boundaries of ARL;
the terminology;
the core principles;
and the minimum viable specification.

Large implementation efforts are not expected yet.

The most valuable contributions today are ideas, critiques and discussion.

## Ways to contribute

We welcome contributions such as:

 * New use cases
 * Threat models
 * Privacy concerns
 * Security analysis
 * Prior art
 * Academic references
 * Terminology improvements
 * Architecture diagrams
 * Integration ideas
 * Questions that challenge existing assumptions

## Before opening a Pull Request

For substantial changes, please open an Issue first.

Discussion should happen before implementation.

The goal is to reach architectural consensus before introducing specification details.

## Design Philosophy

When proposing changes, consider:

 * Does this solve a representation problem rather than a transport problem?
 * Does this belong in ARL instead of A2A or MCP?
 * Does it preserve user sovereignty?
 * Does it minimize identity disclosure?
 * Is it interoperable?
 * Can it remain vendor-neutral?

## Contribution Principles

Every contribution should attempt to improve at least one of the following:

 * Simplicity
 * Privacy
 * Interoperability
 * Security
 * User control
 * Extensibility

Avoid adding complexity without a demonstrated use case.

## Respect Existing Standards

ARL does not aim to replace:

 * MCP
 * A2A
 * OAuth
 * OpenID Connect
 * DID
 * Verifiable Credentials

Whenever possible, ARL should build on existing standards instead of redefining them.

## Be Curious

One of the goals of this repository is to discover whether ARL is actually needed.

If you believe an existing standard already solves part of the problem, we would love to know.

Critical feedback is just as valuable as new ideas.
