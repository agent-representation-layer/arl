# Code of Conduct

## Our Commitment

The Agent Representation Layer (ARL) project aims to build an open, collaborative, and respectful community where people from diverse backgrounds can contribute ideas, ask questions, challenge assumptions, and improve the proposal together.

We are committed to providing a welcoming environment for everyone, regardless of experience level, background, identity, or affiliation.

## Expected Behavior

Participants are encouraged to:

* Be respectful and constructive.
* Assume good intentions.
* Focus discussions on ideas rather than individuals.
* Welcome different perspectives and technical approaches.
* Support evidence-based discussions.
* Be open to changing your mind when presented with better arguments.
* Help create an environment where everyone feels comfortable contributing.

## Unacceptable Behavior

The following behaviors are not acceptable:

* Harassment, discrimination, or personal attacks.
* Insults, trolling, or intentionally inflammatory comments.
* Publishing private information without permission.
* Disruptive or hostile behavior that prevents productive discussion.
* Repeatedly ignoring community guidelines after feedback.

## Design Discussions

ARL is an exploratory project.

Strong technical disagreements are expected and encouraged.

Challenge ideas—not people.

Contributors are encouraged to question assumptions, propose alternatives, identify prior art, and explain trade-offs. Healthy technical debate is one of the project's goals.

## Scope

This Code of Conduct applies to all project spaces, including:

* GitHub Issues
* Pull Requests
* Discussions
* Documentation reviews
* Community meetings
* Any other official communication channels related to ARL

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

They may remove, edit, or reject comments, issues, pull requests, or other contributions that violate these guidelines.

Repeated or serious violations may result in temporary or permanent removal from the project.

## Questions

If you have questions about this Code of Conduct or believe someone has violated it, please open a private discussion with the project maintainers.

## Our Goal

The purpose of ARL is not only to build an open specification, but also to build an open community around it.

We believe the best standards emerge from respectful collaboration, critical thinking, and shared curiosity.
